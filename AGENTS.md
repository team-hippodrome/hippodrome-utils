This repository contains utilities and document used by Team Hippodrome for their ports of the Pokemon Stadium games using libultraship. 

# In-scope ports
| Project | Japanese title | Meaning | Port name |
|---|---|---|---|
| Stadium 0 / Zero | ポケモンスタジアム | Japanese-only original, no Western release | Plethron |
| Stadium 1 | ポケモンスタジアム２ | Western S1 = Japanese “2” | Stadion | 
| Stadium 2 | ポケモンスタジアム金銀 | Western S2 = Japanese “Gold/Silver” | Diaulos|
