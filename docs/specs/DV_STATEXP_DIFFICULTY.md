# What it is
Stat Exp is the Gen 1/2 equivalent of EVs, and DVs are the Gen 1/2 equivalent of IVs. The Stadium games have a variety of Stat Exp and DVs for both rental Pokémon and opponent Pokémon.

This feature lets players set the minimum and maximum Stat Exp and DVs rental and opponent Pokémon can have. The sliders for rental and opponent Pokémon should be listed and configurable separately.

This setting goes in the launcher and the Esc menu.

By default, the values should be set to "vanilla" to use vanilla settings. A slider should appear when the player turns the enhancement on to set the appropriate values. 

Errors should appear for situations where the maximum value is less than the minimum value for a setting.
