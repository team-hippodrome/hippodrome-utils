# What it is
In Stadium 2, you are able to get a description of a move's effects by using the D pad while in the move select menu. The Dpad directions correspond to the C-directions needed to use the move. This enhancement extents this QOL feature to Stadium 1 and Stadium 0.

# Controls
The description shows while the D-pad direction is held, for the move on the C button of the same direction. It is never opened by the C buttons, which still pick the move (Julius, 2026-11-21).
