# What it is
Stat Exp is the Gen 1/2 equivalent of EVs. The Stadium games have a variety of Stat Exp values for both rental Pokémon and opponent Pokémon.

This feature lets players set the minimum and maximum Stat Exp rental and opponent Pokémon can have. The sliders for rental and opponent Pokémon should be listed and configurable separately.

This setting goes in the launcher.

By default, the values should be set to "vanilla" to use vanilla settings. Settings labeled Casual, Easy, Medium, Hard, and Kaizo should be set at every 1/5th of 65535 (max stat exp value) for maximum. These labels are flipped for the minimum
