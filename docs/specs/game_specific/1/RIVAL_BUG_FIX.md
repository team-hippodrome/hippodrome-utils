# What it is
If you do not use a team of only rental pokemon, the Rival fight at the end of the Gym Leader Castle should change its team according to your starter choice (in RBG) or rival victory record (in Yellow). There is an oversight that if a player registers their team it will be counted as a rental team and they will not get the unique Rival fight while using a registered team.

This is fixed by storing the Game Boy starter information of each registered team in a side file.
