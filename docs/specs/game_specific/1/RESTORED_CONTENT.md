# What it is
Stadium 1's various versions had content cut or modified. This enhancement offers restoring their content if the user provides the required ROM

## Nintendo Cup
> ROM required: Japanese

In the international release of Stadium 1 the Nintendo Cups were replaced with Poke Cup because of the fact the Nintendo Cup tournaments only took place in Japan. Stadion offers restoring this content by uploading a Japanese ROM along side an english rom. 

## Gallery
> ROM required: English (any version)
Gallery mode was a mode exclusive to the US release of Stadium 1, although the full data exists in the European English release. It allows players to take pictures of their Pokemon. This enhancements allows non-English roms to access gallery mode if the user provides an English ROM alongside their non-english rom.

## Nidoqueen Animation
> Version Required: Japanese
Nidoqueen had a different animation where she gropes her breasts in the Japanese version. Either animation can be toggled on if a Japanese ROM is provided; otherwise only the animation on the provided ROM is offered.

## Jynx Color
> Version Required: US 1.0 or Japanese for original color, other version for modern color.
Jynx had its color changed from black to purple in later releases of Stadium 1. Either animation can be toggled on if a Japanese ROM or US 1.0 is provided; otherwise only the color on the uploprovidedaded ROM is offered.
